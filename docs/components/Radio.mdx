## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Primary label text. Renders with default SDS typography and error/disabled styling. Ignored when `children` is provided |
| `description` | `string` | — | Optional secondary description below the label. Only rendered when `label` is used (not `children`) |
| `children` | `ReactNode` | — | Free content slot — overrides `label`/`description` when provided. Accepts any non-interactive content: custom layouts, icons, rich text, etc. |
| `checked` | `boolean` | — | Checked state (controlled standalone mode). Omit when inside a RadioGroup — the group manages selection via `value` |
| `defaultChecked` | `boolean` | `false` | Initial checked state for standalone uncontrolled mode. Ignored when `checked` is provided or when inside a RadioGroup |
| `onChange` | `(checked: boolean) => void` | — | Called when this radio is selected |
| `disabled` | `boolean` | — | Prevents interaction. When inside a RadioGroup, the group's `disabled` prop takes precedence unless this is explicitly set to `false` |
| `error` | `boolean` | `false` | Renders error styling on the indicator and label |
| `required` | `boolean` | — | Marks this radio as required for form validation. Prefer setting `required` on the RadioGroup instead |
| `size` | `'medium' \| 'large'` | `'large'` | Visual size |
| `id` | `string` | — | Forwarded to the underlying `<input>` element |
| `name` | `string` | — | `name` attribute for the underlying input. Shared automatically when inside a RadioGroup — only set this for standalone use |
| `value` | `string` | — | Identifies this radio within a RadioGroup's selected value. Required when used inside a RadioGroup |
| `className` | `string` | — | Additional className forwarded to the root `<label>` element |
