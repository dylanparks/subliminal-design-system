## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `'Time'` | Floating label shown inside the field |

| `defaultValue` | `TimeValue \| null` | — | Uncontrolled default value |
| `onChange` | `(value: TimeValue \| null) => void` | — | Called whenever the user changes hour, minute, second, or period; receives `null` when cleared |

| `minuteStep` | `1 \| 5 \| 10 \| 15 \| 30` | `5` | Minute column step |
| `secondStep` | `1 \| 5 \| 10 \| 15 \| 30` | falls back to `minuteStep` | Second column step |
| `disabledTime` | `(value: TimeValue \| null) => DisabledTime` | — | Returns sets of disabled hours/minutes/seconds given the current value |
| `allowClear` | `boolean` | `true` | Show a clear button when the field has a value |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the popover opens or closes |
| `size` | `'large' \| 'medium'` | `'large'` | Visual height: large = 64px · medium = 56px |
| `showLabels` | `boolean` | `true` | Show column header labels (Hour / Minute / Second / AM·PM) |
| `showMinutes` | `boolean` | `true` | Show the minute column |
| `showSeconds` | `boolean` | `false` | Show the seconds column |
| `disabled` | `boolean` | `false` | Disables all interaction |
| `error` | `boolean` | `false` | Error treatment — takes priority over success |
| `success` | `boolean` | `false` | Success treatment |
| `message` | `string` | — | Helper / validation message shown below the field |
| `className` | `string` | — | Additional className forwarded to the root element |
| `name` | `string` | — | Hidden input name for form submission (value is HH:MM or HH:MM:SS in 24h) |
| `aria-label` | `string` | — | Accessible label override (falls back to label prop) |
