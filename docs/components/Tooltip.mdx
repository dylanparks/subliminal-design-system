## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `content` | `string` | — | Brief text label — one short phrase. Never use for critical information |
| `children` | `ReactElement` | — | Single interactive element that triggers the tooltip. Must accept a ref |
| `side` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | Preferred side relative to the trigger. Flips automatically when there is insufficient space on the preferred side |
| `delay` | `number` | `600` | Milliseconds to wait before opening on hover. Focus always opens immediately |
| `disabled` | `boolean` | — | Suppress the tooltip entirely |
