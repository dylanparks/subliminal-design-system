## Props

**Shared (`SliderBaseProps`):**

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | — | Visible group label shown above the track |
| `aria-label` | `string` | — | Accessible name when no visible `label` is provided |
| `min` | `number` | `0` | Minimum value |
| `max` | `number` | `100` | Maximum value |
| `step` | `number` | `1` | Step increment for arrow-key and snap behaviour |
| `largeStep` | `number` | `10 × step`, or ~10% of the range, whichever is larger | Large step for Shift+Arrow and PageUp/PageDown |
| `showValue` | `boolean` | `true` | Show a numeric input next to the label so the user can type an exact value. When false, a tooltip appears over the active thumb during drag/keyboard interaction and auto-dismisses after 1.5s |
| `formatOptions` | `Intl.NumberFormatOptions` | — | Formatting options passed to `Intl.NumberFormat`. Affects `aria-valuetext` and the tooltip/value display |
| `getValueText` | `(value: number) => string` | — | Custom value-to-string formatter. Takes precedence over `formatOptions` when both are provided. Drives `aria-valuetext` and the tooltip/value display |
| `disabled` | `boolean` | — | Disables the field |
| `required` | `boolean` | — | Marks the slider as required for form validation |
| `name` | `string` | — | Forwarded to hidden `<input>` elements for form participation |
| `id` | `string` | — | Forwarded to the root element |
| `className` | `string` | — | Additional className forwarded to the root element |

**`SingleSliderProps`** (`range?: false`):

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | — | Controlled value. Omit for uncontrolled mode with `defaultValue` |
| `defaultValue` | `number` | `min` | Initial value for uncontrolled mode |
| `onChange` | `(value: number) => void` | — | Called when the value changes |

**`RangeSliderProps`** (`range: true`):

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `[number, number]` | — | Controlled `[start, end]` tuple |
| `defaultValue` | `[number, number]` | `[min, max]` | Initial `[start, end]` for uncontrolled mode |
| `onChange` | `(value: [number, number]) => void` | — | Called when the value changes |
