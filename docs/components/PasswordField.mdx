## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `'Input label'` | Floating label shown inside the field (large/medium) or above it (small) |
| `placeholder` | `string` | `'Placeholder content'` | Placeholder text shown inside the input on small size |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled default value |
| `onChange` | `(value: string) => void` | — | Called on every keystroke with the new string value |
| `size` | `'large' \| 'medium' \| 'small'` | `'large'` | Visual height of the field: large = 64px · medium = 56px · small = 48px |
| `disabled` | `boolean` | `false` | Disables the field |
| `error` | `boolean` | `false` | Shows error treatment — takes priority over success |
| `success` | `boolean` | `false` | Shows success treatment |
| `message` | `string` | — | Helper / validation message shown below the field |
| `name` | `string` | — | HTML input name attribute |
| `className` | `string` | — | Additional className forwarded to the root element |
| `aria-label` | `string` | — | Accessible label override (falls back to label prop) |
| `autoComplete` | `string` | `'current-password'` | HTML autocomplete value, so password managers recognise the field even when type switches to text; use `"new-password"` on registration/change-password forms |
| `visible` | `boolean` | — | Controlled visibility — true = password is visible as plain text |
| `defaultVisible` | `boolean` | `false` | Uncontrolled initial visibility |
| `onVisibleChange` | `(visible: boolean) => void` | — | Called when the user toggles password visibility |
