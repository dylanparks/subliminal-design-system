## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `selection` | `'selected' \| 'unselected' \| 'indeterminate'` | `'unselected'` | Selection state of the indicator: `selected` → filled background, checkmark icon; `unselected` → hollow background, no icon; `indeterminate` → filled background, minus/dash icon |
| `size` | `'medium' \| 'large'` | `'large'` | Visual size of the indicator |
| `onMedia` | `boolean` | `false` | Inverts the color scheme for use on media/image backgrounds |
| `disabled` | `boolean` | `false` | Renders the disabled visual appearance |
| `error` | `boolean` | `false` | Renders the error visual appearance |
| `className` | `string` | — | Additional className forwarded to the indicator element |
